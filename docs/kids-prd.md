# 儿童模式 PRD v2（全局时间管控）

> 状态：v2 重构稿。v1 的「每应用独立额度 + 答题/PIN 每应用解锁」废弃，改为**全局共享额度 + 全局 6 位家长密码**。
> 本文档定义「做什么、做成什么样」，实现细节见各源码文件注释。

## 1. 目标

- 全局 6 位家长密码，初始 `313074`，统一替换旧 4 位 PIN，用于：电视设置、隐藏应用、儿童模式设置入口、超时解锁。
- 应用分三类：
  - **不限制（Free）**：儿童可任意使用，不计时。
  - **完全禁止（Blocked）**：儿童模式下永远打不开。
  - **受限计时（Timed）**：仅允许时段内可用，使用时长计入**全局每日总时长**。
- 所有受限应用**共用**一个每日总时长（统计窗口 00:00-24:00），用完后**所有**受限应用一起拦截（拉回桌面、暂停播放）。
- 保留「时段」：配置的时段外，受限应用完全不可用（不做题、不加时，只能家长密码）。
- 做题可加时：全局生效（答对 1 题 = 2 分钟，单轮封顶 20 分钟），家长可关。
- 儿童模式开启时，Home 屏幕显示：今日剩余时间 / 已用时间 / 管控时间；无法获取使用统计时不显示「剩余/已用」，只显示「管控时间」。

## 2. 应用分类（电视/手机页均可配置）

| 分类 | 行为 |
| --- | --- |
| 不限制 Free | 不拦截、不计时 |
| 完全禁止 Blocked | 儿童模式锁定状态下无法打开，提示 + 仅家长密码 |
| 受限计时 Timed | 时段外拦截；时段内计入全局额度，额度用完拦截 |

## 3. 拦截与超时流程

1. 前台应用被拦（打开即拦，或 10 秒轮询兜底）→ Home Guard 拉回桌面，应用进后台、播放暂停。
2. 桌面提示页（KidsTimeUp）：
   - **完全禁止**：标题「该应用儿童不可使用」，按钮：家长密码 / 返回首页。
   - **时段外**：标题「当前时段不可用」，正文「请在允许时段使用」，按钮：家长密码 / 返回首页（无做题）。
   - **额度用完**：标题「今日使用时间已经达上限」：
     - 允许做题 → 正文提示可答题加时，按钮：做题加时 / 家长密码 / 返回首页。
     - 不允许做题 → 正文「请于明早 9:00 后使用」，按钮：家长密码 / 返回首页。
3. 家长密码正确 → **家长选项菜单**：
   - 打开设置（进儿童模式管理面板）
   - 今日不在管控（当天所有限制解除，跨天自动恢复）
   - 延长 10 分钟 / 20 分钟 / 30 分钟（计入今日总额度）

## 4. 家长密码（统一，替换旧 PIN）

- 6 位数字，初始 `313074`，SHA-256 存储；一经初始化始终存在，可修改、可重置。
- 解锁后 10 分钟内存态，按 Home 键立即重新锁定（沿用旧 PIN 机制）。
- 修改入口：个性化 → 家长密码 → 修改（进入前已解锁）。
- 忘记：`adb shell am broadcast -a app.orchard.tv.CONFIG -n app.orchard.tv/.guard.ConfigReceiver --ez clear_pin true` → 重置为 313074。
- 解锁态（10 分钟内）儿童模式不拦截：家长输入密码后即可自由使用/配置。

## 5. 状态与统计

- 统计窗口 00:00-24:00；跨天自动重置：已用、做题获得、延长、今日免管控。
- 已用 = 全部受限应用前台时长之和（`GET_USAGE_STATS`）。
- 剩余 = 管控时间 + 做题获得 + 延长 − 已用。
- 管控时间默认 60 分钟，可选 0(不限)/30/60/90/120，家长可改。
- 时段默认「全天」，预设可选 07:00-19:00 / 08:00-20:00 / 09:00-21:00。
- 无法获取使用统计（`GET_USAGE_STATS` 未授权）时：不显示剩余/已用，额度判断失效，仅时段与完全禁止生效。
- Home Guard `restricted = 儿童模式开启 && 家长密码锁定 && 未今日免管控`。

## 7. 验收标准

1. 儿童模式开启，把应用 A 设为受限计时、B 设为完全禁止、C 不限制：
   - Home 顶部显示「剩余/已用/管控」；未授权使用统计时只显示管控时间。
   - 打开 B → 「该应用儿童不可使用」；打开 C → 正常。
2. 全局额度（如 30 分钟）用完后：A 被拉回桌面，提示「今日使用时间已经达上限」；做题加时后 A 可再开；不允许做题时提示「请于明早 9:00 后使用」。
3. 家长密码（313074）在超时页进入家长选项：今日不在管控后所有应用可开；延长 10/20/30 分钟计入总额度。
4. 家长密码同时替代旧 PIN 拦截电视设置/隐藏应用；修改密码后新密码生效。
5. 编译通过，电视端到端流程走通。
